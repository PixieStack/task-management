╔══════════════════════════════════════════════════════════════╗
║     🚀 COMMANDS TO RUN YOUR APPS IN VS CODE TERMINAL 🚀     ║
╚══════════════════════════════════════════════════════════════╝

📝 You need TWO separate terminal windows in VS Code.

════════════════════════════════════════════════════════════════
TERMINAL 1: BACKEND (FastAPI)
════════════════════════════════════════════════════════════════

Copy and paste these commands one by one:

cd /app/backend
source /root/.venv/bin/activate
python -m uvicorn server:app --reload --host 0.0.0.0 --port 8001

✅ When you see "Application startup complete", backend is ready!
✅ Access: http://localhost:8001/docs


════════════════════════════════════════════════════════════════
TERMINAL 2: FRONTEND (Angular)
════════════════════════════════════════════════════════════════

Copy and paste these commands one by one:

cd /app/frontend
yarn start

✅ Wait ~30 seconds for compilation
✅ When you see "Compiled successfully", frontend is ready!
✅ Access: http://localhost:3000


════════════════════════════════════════════════════════════════
🎯 TESTING THE APPS
════════════════════════════════════════════════════════════════

   http://localhost:8001/docs

   http://localhost:3000

════════════════════════════════════════════════════════════════
🛑 TO STOP THE APPS
════════════════════════════════════════════════════════════════

In each terminal window:
Press: Ctrl + C

Or close the terminal windows.


════════════════════════════════════════════════════════════════
🔍 TROUBLESHOOTING
════════════════════════════════════════════════════════════════

❌ If Backend shows "Address already in use":
sudo supervisorctl stop backend
lsof -ti:8001 | xargs kill -9
# Then try running backend command again

❌ If Frontend shows "Address already in use":
sudo supervisorctl stop frontend
lsof -ti:3000 | xargs kill -9
# Then try running frontend command again

❌ If Backend shows "ModuleNotFoundError":
cd /app/backend
source /root/.venv/bin/activate
pip install -r requirements.txt
# Then try running backend command again

❌ If Frontend shows errors:
cd /app/frontend
yarn install
# Then try running frontend command again
