What “supported” means

macOS

The Universal package contains both Intel x86_64 and Apple Silicon arm64 code. A 2019 Intel MacBook uses the Intel side; current M-series Macs use the Apple Silicon side.

iPhone / iPad

A native iOS app requires Apple signing and provisioning before it can be installed on a physical device or distributed through TestFlight or the App Store.

Windows

Separate x64 and ARM64 package targets are configured so Intel/AMD PCs and ARM Windows devices can use native installers built for their architecture.

Android

The build pipeline can create an APK for direct device testing and can be prepared for a signed store release. Production distribution requires a persistent release signing key.
